Overview

This product is a dual-band broadband gateway that combines a router, a 4-port Gigabit switch, and a USB storage-sharing port in one unit — the same class of device described in the Specifications chapter. It's meant to sit between your internet connection (fiber ONT, cable modem, or DSL modem) and the devices on your local network.

Key Features

  • Simultaneous dual-band Wi-Fi (2.4 GHz and 5 GHz)
  • 4× Gigabit Ethernet LAN ports, 1× Gigabit WAN port
  • USB 2.0 port for shared network storage or a printer
  • Web-based and command-line configuration — see Initial Setup
  • Remote firmware updates — see Advanced Topics

Safety Warnings

Right after the box contents is where safety warnings usually go, before anyone touches a cable — these use the .callout pattern (four variants: callout-note, callout-tip, callout-warning, callout-danger), color-coded independently of the active brand so they stay recognizable no matter the theme.

Danger

Disconnect the power adapter before cleaning the device or connecting/disconnecting any cable. Never open the enclosure — there are no user-serviceable parts inside.

Warning

Use only the power adapter supplied with the device. Using a different adapter can damage the unit and voids the warranty.

Note

Install the device in a well-ventilated area, away from direct sunlight and heat sources, for reliable long-term operation.

Tip

Keep the original packaging for the first 12 months — it's the easiest way to ship the device back in for warranty service.
