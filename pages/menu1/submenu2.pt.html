Configuração Inicial

Depois que o dispositivo estiver instalado fisicamente (veja Instalação), este capítulo mostra a configuração inicial — tanto pela interface web quanto pela linha de comando.

Acessando a Interface Web

Conecte um computador a qualquer porta LAN (ou à rede Wi-Fi padrão impressa na etiqueta do dispositivo) e abra http://192.168.1.1 em um navegador.

Nota

O nome de usuário administrador padrão é admin; a senha padrão está impressa na etiqueta do dispositivo. Você será solicitado a definir uma nova senha no primeiro login.

Exemplo de Configuração via Linha de Comando

Manuais de roteador/switch/gateway costumam incluir uma sessão de linha de comando para copiar e colar — o padrão .cli-block abaixo é um <pre><code> simples estilizado como um terminal.

login as: admin
admin@192.168.1.1's password:

device> configure
device(config)> interface wan0
device(config-if)> ip address dhcp
device(config-if)> exit
device(config)> save
Configuration saved.

Dica

Prefere a interface web? A mesma configuração fica em Rede → WAN → Atribuição de IP.
