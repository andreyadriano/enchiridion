Advanced Topics

Reference material for more experienced users: terminology, resetting/backing up the device, and how to update its firmware.

Resetting the Device

A short power cycle (unplug for 10 seconds) resolves most temporary issues without losing any settings. A full factory reset — covered in Firmware Update Procedure below — erases all custom configuration and should only be used as a last resort.

Backing Up Your Configuration

Before a factory reset or a firmware update, export your current settings from System → Backup & Restore → Download Backup File. The downloaded file can be re-imported from the same page to restore every setting in one step.

Firmware Update Procedure

A firmware-update procedure combines two patterns already shown elsewhere in this demo manual — a warning callout up front, then numbered .steps.

Warning

Do not disconnect power or the network cable during a firmware update. An interrupted update can make the device unusable and may require service to recover.

  1. Download the latest firmware file for your exact model from the manufacturer's support site.
  2. Open the web interface and go to System → Firmware Update.
  3. Select the downloaded file and click Upload.
  4. Wait for the update to finish and the device to restart on its own — this can take up to 5 minutes.
  5. Confirm the new version number under System → Status.

Tip

To restore factory defaults instead, press and hold the recessed Reset button for 10 seconds while the device is powered on.
